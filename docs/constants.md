# <kbd>module</kbd> `constants`

## Cosmology Constants

**Global Variables**
---------------
- **PLANCK18_OMEGAM** - Matter density from Planck 2018 cosmology (0.30966)
- **PLANCK18_H0** - Hubble constant in km/s/Mpc from Planck 2018 (67.66)
- **PLANCK18_TH** - Hubble time in Gyr from Planck 2018 (14.45155515)
- **SPEED_OF_LIGHT** - Speed of light in km/s (299792.458)

## Filter and Photometry Constants

**Global Variables**
---------------
- **COSMOS_FLUX_SOFTENING** - Flux softening parameters for COSMOS bands in nanomaggies (AB system)
- **COSMOS_FILTERS** - List of COSMOS filter names in the order used by pop-cosmos
- **COSMOS_FILTERS_LATEX** - LaTeX formatted names for COSMOS filters

## SPS Parameter Constants

**Global Variables**
---------------
- **PARAMETER_NAMES** - List of base SPS parameter names reflecting the parameter order returned by catalogue generation functions
- **PARAMETER_NAMES_LATEX** - LaTeX formatted names for SPS parameters

## Calibration Constants (Leistedt+23)

**Global Variables**
---------------
- **ZEROPOINTS_LEISTEDT23** - Flux zero point corrections for COSMOS filters (fractional corrections)
- **ERRORFLOOR_LEISTEDT23** - Flux error floors for COSMOS filters (fractional error floors)
- **EMLINEOFFSETS_LEISTEDT23** - Emission line offsets (fractional correction)
- **EMLINEERRORS_LEISTEDT23** - Emission line strength standard deviations (fractional)
